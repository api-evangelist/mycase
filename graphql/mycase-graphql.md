# MyCase GraphQL API

MyCase is a cloud-based legal practice management platform. The API covers cases/matters, contacts, time entries, invoices, payments, documents, calendar events, tasks, and communication threads for law firms.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from MyCase REST API
**Documentation:** https://mycaseapi.stoplight.io/docs/mycase-api-documentation/k5xpc4jyhkom7-getting-started
